## [1.0.0] - 2026-08-27

### Added

- USB Consumer HID receiver-button learning and confirmation.
- Fn, standard key, alphanumeric key, function key, and custom shortcut mappings.
- Immediate and hardware-gesture-preserving response modes.
- Input Monitoring and Accessibility permission guidance.
- In-app Simplified Chinese and English language switching, with Simplified Chinese as the first-launch default.
- Localization validation and GitHub Actions CI.
- Universal 2 release packaging and checksum generation, with an explicitly labeled unnotarized distribution option.
