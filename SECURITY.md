# Security Policy

## Supported versions

The latest published MicKey release receives security fixes.

## Reporting a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/orange90/insta360mic2typelss/security/advisories/new). Do not open a public issue for a suspected vulnerability and do not include signing or notarization credentials in reports.

Include the MicKey version, macOS version, a minimal reproduction, and the potential impact. Please allow a reasonable period for investigation before public disclosure.
